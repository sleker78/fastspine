# Getting Started with FastStack

Welcome to FastStack! This section will get you up and running quickly.

## Learning Path

Follow these guides in order for the best learning experience:

### 1. **[Hello World](hello-world.md)** ⭐ *Start Here*
The absolute simplest FastStack application in a single file. Perfect for understanding core concepts without complexity.

**What you'll learn:**
- Basic dependency injection
- Repository and Service patterns
- Single database setup
- API endpoint creation

**Time: 10 minutes**

---

### 2. **[Installation](installation.md)**
Complete installation guide with different package managers and optional dependencies.

**What you'll learn:**
- uv vs pip installation
- Database drivers setup
- Development tools
- Docker configuration

**Time: 15 minutes**

---

### 3. **[First App Tutorial](first-app.md)**
Complete blog application showing advanced FastStack patterns with multi-database architecture.

**What you'll learn:**
- Multi-database setup
- Primary vs Secondary databases
- Alembic migration strategy
- Service orchestration
- Caching integration

**Time: 30 minutes**

---

### 4. **[Configuration](configuration.md)**
Advanced configuration patterns for production applications.

**What you'll learn:**
- Environment-specific settings
- Database configuration
- Cache settings
- Production deployment

**Time: 20 minutes**

---
